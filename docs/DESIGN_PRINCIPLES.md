# Design Principles

## Reality Before Interpretation

Save facts before generating interpretation.

```text
Reality → Evidence → Interpretation
```

## Evidence Before Identity

Identity is not a label. It emerges from observed events, repeated patterns, validated interpretations, and formation paths.

```text
Observed Event → Repeated Pattern → Validated Interpretation → Formation Path
```

## Formation Before Prediction

Future judgment should be reconstructed from formation paths, not from simple memory retrieval.

## Extractor Is Not Governance

The extractor can say:

> This evidence may indicate an identity-relevant continuity structure.

It must not say:

> This is now part of the persona.

## Portable by Default

Persona Packages should be portable across Persona Host implementations and consumable by Julia Core-compatible runtimes.
